# AS-305: the Medallion's declared price

**Tier: DIRECTIONAL** (a node arm, talents proposal §4 and §6.5 item 4). **Question:** what is
the Medallion's crowd-control break worth in item budget, so its declared price can stand?
**Success condition:** the Medallion, played against an item of the same budget spent on health,
measures level within the run's resolution.

**Answer:** the break is worth about **18 budget points** (18 health). The Medallion ships as
the break at a declared 18 plus 30 health, its Champion trinket budget (48.3). Against 48 health
it measures **-0.24pt (95% +-0.37), McNemar z=1.93**: level.

## Method

- **Cells.** Every 2v2 on BasicArena with a wearer class X in team 1 slot 0 and a partner P,
  against every distinct enemy pair; no double-healer side. 60 x 30 = 1,800 cells.
- **Seeds.** Three blocks of 4 seeds (305000+, 306000+, 307000+): 7,200 matches a block,
  21,600 an arm. Per-class effects are read in each block separately and pooled.
- **Arms.** Same binary (`fe64dd6b`, copied with its own `assets/` beside it, which
  `paths::assets_dir` reads first), same JSONL. The wearer's Trinket2 is the Medallion. Only its
  `items.ron` entry differs between arms:

  | Arm | Medallion entry |
  |---|---|
  | `0` | not equipped (the default loadouts carry no Trinket2) |
  | `H24` / `H48` | `max_health: 24.0` / `48.0`, no `on_use` |
  | `M48` | the break at `price: Some(48.0)`, no stats |
  | `M20` | the break at 20, `max_health: 28.0` |
  | `M18` (shipped) | the break at 18, `max_health: 30.0` |

- **Score.** The wearer's team: win 1, draw 0.5, loss 0. Deltas are paired at identical seeds;
  the interval is from the paired differences, so it is set by the matches that flipped.

## Results

| Pair | Delta (pt) | 95% | Flips for / against | McNemar z |
|---|---|---|---|---|
| H24 vs 0 | +2.59 | 0.32 | 982 / 393 | 15.9 |
| H48 vs 0 | +5.36 | 0.43 | 1,813 / 594 | 24.8 |
| M48 vs 0 (the break alone) | +2.19 | 0.26 | 665 / 187 | 16.3 |
| M48 vs H48 | -3.17 | 0.47 | 1,050 / 1,789 | 13.9 |
| M20 vs H48 | -0.44 | 0.38 | 852 / 984 | 3.1 |
| **M18 vs H48** | **-0.24** | **0.37** | **836 / 918** | **1.9** |

Health is linear here (24 is half of 48's effect), at about 0.11pt a point. The break alone is
worth +2.19pt, about 20 health; M20's small shortfall puts it nearer 18.

**Per wearer class, M18 vs H48** (pt, seed blocks 0 / 1 / 2, pooled with 95%):

| Class | Blocks | Pooled |
|---|---|---|
| Druid | +2.1 / +1.2 / +1.5 | +1.6 (1.6) |
| Shaman | +1.5 / +2.2 / +0.4 | +1.4 (1.3) |
| Priest | +2.9 / +0.4 / +0.2 | +1.2 (1.3) |
| Rogue | +0.4 / +0.7 / +0.1 | +0.4 (0.9) |
| Hunter | -1.1 / +0.1 / -0.8 | -0.6 (0.9) |
| Warrior | +0.2 / -0.2 / -1.9 | -0.6 (0.9) |
| Paladin | -0.1 / -1.8 / -0.1 | -0.7 (1.3) |
| Mage | -1.8 / -1.4 / +0.4 | -0.9 (1.0) |
| **Warlock** | **-2.4 / -2.2 / -1.8** | **-2.2 (1.1)** |

- **Warlock is the one class beyond its interval, in all three blocks.** Health is worth twice
  as much to it as to most classes (H48 vs 0: +10.0pt against +5.4 overall; Life Tap spends it),
  so against a health control any non-health item reads low for the Warlock. That is the
  control's stat, not the break. A Warlock is better served by the stat trinket.
- **The healers lean the other way** (Druid, Shaman, Priest +1.2 to +1.6, each interval touching
  zero): the break is worth a little more to the unit the enemy crowd-controls.

## How often it fires

Over 180 traced Medallion matches (every 120th of the sweep's JSONL), the wearer was held at all
in 31 and broke free in 9 (5%). Held units are mostly Warriors and Hunters; the healers and
casters in this set are rarely stunned, feared or polymorphed. Of the 41 holds, 36 began with
the AI rule's trigger unmet: the teammate was at 50% or above in 34 (the wearer had none in 2),
and the wearer was not the enemy's kill target. The break's price is therefore
the price of the rule as written (§6.4); a wider rule would use it more, and would need a new
measurement.

## Reproduce

```bash
# cells: scratch generator, 1,800 cells x 4 seeds per block, blocks 0-2
for b in 0 1 2; do python3 gen.py $b 4 medallion >> med.jsonl; done
# one arm per assets copy beside a copied binary; edit only the Medallion's entry
armX/arenasim --batch med.jsonl --out armX.csv --jobs 3 --trace-mode off
```

`gen.py` emits, for each X, P and enemy pair as above, `{"team1": [X, P], "team2": [E1, E2],
"random_seed": 305000 + 1000*block + k, "max_duration_secs": 300, "team1_equipment":
[{"Trinket2": "MedallionOfTheAlliance"}, {}]}`; arm 0 omits `team1_equipment`.
